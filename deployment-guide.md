# PageDrop Deployment

1. Connect the GitHub repository to Vercel.
2. Add storage/database environment variables in Vercel Project Settings.
3. Configure the root domain and wildcard routing with the DNS records required by the chosen Vercel setup.
4. Add the domain property to Google Search Console, create the TXT verification record, and verify ownership.
5. Set NEXT_PUBLIC_APP_URL to the public PageDrop origin.
